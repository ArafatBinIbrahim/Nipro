# Nipro Agency – Responsive HTML Template

Nipro Agency is a clean, modern, and fully responsive HTML template designed for creative agencies, design studios, and freelance portfolios. It combines a minimal black-and-white aesthetic with bold typography and smooth section transitions to showcase services, team, pricing, and portfolio work.

## ✨ Features

- **Hero Slider** – Full-screen background slider with headline, description, "Learn More" CTA, and previous/next navigation
- **Welcome Section** – Brief agency introduction
- **Services (Branding) Cards** – 4-column icon cards with title, description, and "More" link
- **About Us** – Image + text layout describing the agency
- **Portfolio Grid** – 2x2 image grid showcasing project titles and categories (App Design, etc.)
- **Why Choose Us** – Feature grid covering Retina Display, Full Responsive, Updates & Support, Easy to Customize
- **Team Section** – "Who Work With Us" — team member cards with photo, name, and role
- **Pricing Plans** – 4-tier pricing table (Basic, Standard, Enterprise, Platinum) with storage, members, projects, bandwidth, and support details, each with a "Sign Up" CTA
- **Template CTA Banner** – "Nipro | Responsive HTML Template" banner with "Buy Now" button
- **Founder/Team Spotlight** – Circular profile card with name, role, and bio
- **Contact Form** – Message textarea with "Send Now" button
- **Footer** – Agency tagline, social media icon links (Facebook, Dribbble, Behance, Twitter, LinkedIn, Google+), copyright, and utility links (Support, Sitemap, Contact US, Terms of Use)
- **Responsive Navigation** – Hamburger menu for mobile-friendly browsing

## 🚀 Getting Started

Since this is a static HTML template, no build step is required.

```bash
git clone https://github.com/your-username/nipro-agency.git
cd nipro-agency
# Simply open index.html in your browser
```
